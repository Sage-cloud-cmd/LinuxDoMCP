不用记任何命令，像跟人说话一样就行。可以直接复制下面这些：

看看我的 L 站通知和书签

读帖有三种方式，AI 会自己挑，你也可以点名要

按楼号读全文从 1 楼往下读，一次 100 楼，长帖会自动翻页。适合想看完整讨论的时候。说「从头读一遍」
高赞评论楼主原帖，加上按点赞从多到少排的评论，被采纳的答案排第一。适合提问、求助、踩坑帖。说「看看高赞评论」

不知道还能干什么？直接问 AI：「你有哪些 L 站工具？分别怎么用？」每个工具都带说明，AI 会讲给你听。

遇到问题

自检说「扩展没连上」

确认 Chrome 开着，并且在 chrome://extensions 里「linux.do MCP 桥」是启用状态。刚打开 Chrome 的话，等半分钟再试。

提示「Cloudflare 要求验证」

在 Chrome 里打开一次 https://linux.do，等页面正常显示（有时会先转一下验证），再让 AI 重试。

提示「L 站在限流」

L 站最近自己就常限流，跟你的操作关系不大。等一两分钟再问。别让 AI 一口气读太多帖子。

Chrome 最左边多了一个固定的 L 站标签页

这是扩展自己的工作页，AI 的请求都在那里发，不会动你自己开的 L 站页面。关了也没事，下次用时会自动再开。

AI 说它没有 L 站工具

回到第 4 步，确认 AI 工具已经完全重开。还不行的话，重新运行一次第 1 步的安装，看窗口里你的工具那一行是不是 ✓。

杀毒软件拦了 linuxdo-mcp.exe

选择「信任」或「允许」。这个程序只在你电脑上和 Chrome 扩展通信，只访问 linux.do。

用别的电脑或别的 Chrome 账号

扩展装在哪个 Chrome 里，就用哪个 Chrome 里登录的 L 站账号。换电脑要重新装一遍。

不想用了

在终端里运行下面这行，再到 chrome://extensions 移除「linux.do MCP 桥」：

在 cmd 黑窗口里运行下面这行，再到 chrome://extensions 移除「linux.do MCP 桥」：

~/.linuxdo-mcp/linuxdo-mcp uninstall
"%LOCALAPPDATA%\linuxdo-mcp\linuxdo-mcp.exe" uninstall

它会从各个 AI 工具里撤掉登记，并删除程序。改过的配置文件旁边都留了 .bak-linuxdo 备份。
